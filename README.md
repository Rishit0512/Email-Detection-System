# Email-Detection-System
Developed a machine learning-based Email Spam Detection System using Python and Flask to classify emails as spam or safe in real time. Implemented NLP preprocessing, TF-IDF vectorization, and ML classification using a public dataset to demonstrate cybersecurity threat detection concepts.

## Overview

The Email Spam Detection System is a machine learning-based web application developed using Python and Flask that classifies email messages as either Spam or Safe (Ham) in real time. The project demonstrates practical applications of cybersecurity, natural language processing (NLP), and machine learning techniques for identifying potentially malicious or unwanted email content.

The system analyzes user-provided email text, processes the content using text preprocessing techniques, and predicts the classification using a trained machine learning model through an interactive Flask-based web interface.

## Key Features

* Real-time spam email detection
* Machine learning-based text classification

## Dataset & Model

The model was trained using a publicly available spam email dataset containing labeled spam and ham (safe) messages. The implementation uses built-in machine learning and NLP libraries for preprocessing, feature extraction, and classification.

Text preprocessing techniques included:

* Lowercasing
* Tokenization
* Removal of punctuation and stopwords
* TF-IDF Vectorization

The project focuses on building a lightweight and practical spam filtering solution suitable for learning cybersecurity and machine learning fundamentals.

## System Workflow

1. User enters email content into the web application
2. Email text is cleaned and preprocessed
3. TF-IDF vectorization converts text into numerical features
4. The trained machine learning model analyzes the content
5. The system predicts whether the email is:

   * Spam
   * Safe (Ham)
